# 마계마을 · 붉은 달의 길

첫 번째 게임과 독립된 2D 고정 사이드뷰 횡스크롤 게임입니다. 배경은 이 게임 전용으로 생성한 `assets/demon-village-background.png`를 사용합니다. 악마 캐릭터는 별도로 만든 픽셀 스타일 캐릭터입니다. 게임 장면은 WebGL 텍스처로 표시하며, WebGL을 사용할 수 없는 브라우저에서는 2D Canvas로 표시합니다.

- `←` `→`: 이동
- `Space`: 점프
- `↑` / `↓`: 쇠사슬 사다리 오르내리기
- `J`: 불꽃 공격
- `P`: 일시정지
- 화면 아래 버튼으로 터치 조작 가능

불꽃을 모으고 적을 공격하거나 피해 마왕성의 문에 도착하면 완주합니다. 체력은 세 칸이며 중간 지점을 지나면 그곳에서 다시 시작합니다.

배경 이미지와 플레이 발판은 같은 월드 좌표를 사용합니다. 집 앞 낮은 지형, 중앙 공중 바위, 작은 중간 바위, 오른쪽 높은 관문과 아래쪽 지형에 충돌 판정을 배치했습니다. 그림 속 쇠사슬 사다리 두 곳은 실제로 오르내릴 수 있습니다. 악마 캐릭터는 좌우 방향 전환과 여섯 단계 달리기 포즈를 코드에서 그립니다.

`demon-village-runner/` 경로에서 실행합니다.
